# 🐱 HTTP Response Status Codes

🚀 An interactive web project to learn and explore **HTTP Response Status Codes** using fun images from **HTTP Cat**.

🔎 Enter an HTTP status code such as `200`, `404`, or `500`, and the application will display the corresponding image.

## ✨ Features

* 🔎 Search HTTP response status codes
* 🐱 Display the corresponding HTTP Cat image
* 🎨 Simple and clean user interface
* 📱 Responsive design for different screen sizes
* 🖱️ Interactive image hover effect
* ⚡ Dynamic card creation using JavaScript
* 🔧 DOM manipulation
* 🔍 Font Awesome search icon

## 🛠️ Technologies Used

* 🌐 **HTML5**
* 🎨 **CSS3**
* ⚡ **JavaScript**
* 🔧 **DOM Manipulation**
* 🔍 **Font Awesome**
* 🐱 **HTTP Cat**

## ⚙️ How It Works

1. ✍️ Enter an HTTP status code in the search box.
2. 🔍 Click the search button.
3. ⚡ JavaScript gets the entered status code.
4. 🃏 A new card is created dynamically.
5. 🐱 The corresponding HTTP Cat image is displayed.

### 💡 Example

If you enter:

```text
404
```

The application loads:

```text
https://http.cat/404
```

🐱 The corresponding HTTP status code image will then appear on the page.
